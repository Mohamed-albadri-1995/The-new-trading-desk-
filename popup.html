🔎 Screener
📋 Candidate Registry
Every scan writes its results here first, then the Screener cards are built from this registry — so candidates that were live earlier in the day aren't lost when a later scan no longer returns them. Each ticker + day is one record: a stock that reappears the same day updates its row, the same ticker on a new day starts a fresh row, and past days are kept untouched for the record.
⭐ Shortlist
Tap ☆ Shortlist on any Screener card to add it to today's list. Each trading day gets its own collapsible section — when the date rolls over, a fresh empty list starts and past days stay saved here. Export a day to copy its symbols (TradingView format) for Watchlist › Import, or save a .txt. Every export is logged below its day with the exact time.

⚙ Settings
🔥 Hot Sector Thresholds
A sector turns 🔥 HOT when its score reaches the immediate threshold instantly, or holds at/above the sustained threshold for the set number of sessions (one session = one trading day you refresh). Once hot, it stays hot as long as its score holds above the floor — it only cools off after sitting below the floor for more than the set number of cooling sessions. So a normal pullback won't un-hot a leader; only a real breakdown will.
📰 News — Finnhub API Key
Used to pull company-news summaries onto screener cards. Grab a free key at finnhub.io (60 calls/min on the free tier). TradingView headlines are fetched without a key on a best-effort basis (unofficial endpoint, titles + links only). News loads per-card on demand to stay within the rate limit.
